# 필요한 API 키와 추가 수집 데이터

작성 기준: 2026-11-22(KST). "확인" 열이 **관측**인 것만 이번 작업에서 직접 본 것이다. **기억**은 작성자의 기억에 기반한 후보로, 서비스의 현재 이름·제공 범위·신청 절차를 확인하지 않았다. 신청 전에 각 사이트에서 다시 확인한다.

이 문서는 후보 목록이다. 이후 일부 출처를 실제로 확인했고, 계층별 구성과 확인 결과는 [07 문서](07-data-composition.md)에 있다. 두 문서가 다르면 07 문서를 따른다.

계정 생성과 키 발급은 계정 소유자가 직접 한다. 발급받은 키는 `.env`에만 두고 Git에 넣지 않는다(`.gitignore`에 반영).

## 1. API 키

### 먼저 필요한 것

| 대상 | 얻는 것 | 쓰는 단계 | 확인 |
|---|---|---|---|
| 국가법령정보 공동활용 Open API(`open.law.go.kr`) | 법률·시행령의 조항호 단위 본문, 자치법규 목록·본문·별표, 행정규칙, 법령해석례, 조문별 변경 이력 | 1단계 | 제공 항목은 안내 목록에서 관측. 신청 절차와 인증값은 기억 |
| 임베딩 모델 접근 | 조문 검색용 벡터. 참고 저장소는 Hugging Face 토큰(`HF_TOKEN`)으로 `multilingual-e5-large`를 호출했다 | 3단계 | 참고 저장소 문서에서 관측. 로컬 실행으로 대체할 수 있음 |
| 생성 모델 접근 | 규제 카드 추출과 보고서 생성. 참고 저장소는 Vertex AI의 Gemini를 썼다 | 3단계, 5단계 | 참고 저장소 문서에서 관측. 어떤 모델을 쓸지는 미정 |

법령 API가 가장 급하다. 조례 이름을 추측해 여는 방식은 빠지는 조례가 생기고 최신 연혁인지도 확실하지 않았다([04 문서](04-stage0-udo-source-list.md) 6절).

### 이후 단계에서 검토할 것

| 대상 | 얻는 것 | 쓰는 단계 | 확인 |
|---|---|---|---|
| 공공데이터포털(`data.go.kr`) 인증키 | 관광·교통·환경 통계의 공개 API. 한국관광공사 관광 정보, 여객선 수송 실적 등이 후보 | 6단계 | 기억 |
| 제주데이터허브 | 제주 지역의 관광·유동인구·소비 데이터. 참고 저장소가 목록 엑셀을 기다리던 출처 | 6단계 | 참고 저장소 문서에 이름만 관측 |
| 브이월드 등 공간정보 API | 용도지역, 공원구역, 보전지역 등의 지도 데이터 | 6단계 | 기억 |
| 국가유산청 공개 API | 천연기념물 등 국가유산의 지정 정보와 구역 | 6단계 | 기억. 포털의 웹 페이지는 관측 |

## 3. 우선순위

1. **법령 API 신청.** 1단계 전체가 여기에 걸려 있다.
2. **우도 운행제한 연장 공고 확보.** 게시판에 없으면 교통정책과에 문의한다.
3. **생성·임베딩 모델 결정.** 참고 저장소의 것을 그대로 쓸지 정한다.
4. 공간 데이터와 부하 지표는 규제 베이스가 선 뒤(6단계)에 시작한다.

## 4. 수집할 때 지킬 것

- 각 자료의 이용 조건과 재배포 조건을 확인하고 기록한다. 확인 전에는 원문을 Git에 넣지 않는다.
- 웹 페이지를 읽어 얻은 자료는 수집 시각과 주소를 남긴다. 공식 API가 있으면 API를 쓴다.
- 통계의 집계 단위(월·지역)를 그대로 유지한다. 집계 통계를 개별 장소나 개인 수준으로 바꿔 쓰지 않는다.
