|---|---|

| 조례에서 뽑은 블록의 출처를 법률로 잘못 적은 카드 | 실패 3건으로 잡아냄 |
| 조례 제6조 39개 호의 인용문이 제6조 안에 있는가 | 39개 모두 제6조 안에 있음(일회성 점검) |

실행 방법:

```
python scripts/check_card_quotes.py data/cards/udo-vehicle-restriction-2026-715.json
python scripts/check_card_quotes.py data/cards/jeju-absolute-conservation-area.json
python scripts/check_card_quotes.py data/cards/jeju-relative-conservation-area.json
```

이 검사가 보는 것과 보지 않는 것은 다음과 같다.

- 본다: 인용문이 지정된 원문에 글자 그대로 있는가. 원문 파일이 카드를 만들 때와 같은가.
- 보지 않는다: 인용문이 `locator`에 적힌 조·항·호 안에 있는가. 짧은 인용문은 다른 조문에도 나올 수 있다. 조례 제6조에 대해서는 따로 점검했지만 스크립트에는 넣지 않았다.
- 보지 않는다: 요약이 인용문의 뜻을 바르게 옮겼는가, 빠뜨린 조건이 없는가. 사람이 검수한다.

## 3. 설계에서 바뀐 점

### 02 문서의 가정과 달랐던 것

| 02 문서의 가정 | 실제로 필요했던 것 |
|---|---|
| 카드 하나에 대상 행위 하나 | 제한 대상이 여러 묶음이고 묶음마다 세부 조건과 단서가 있다. 중첩 구조가 필요하다 |
| 금지 내용만 기록 | 예외가 판정에 똑같이 중요하다 |
| 수치 기준 한 칸 | 벌칙이 여러 갈래이고 형태가 다르다 |
| 시행 상태 4값(시행·유예·논의·폐지) | 기간이 끝났는데 후속 공고를 못 찾은 상태(`unconfirmed`)가 필요하다 |
| 카드 하나에 조문 하나 | 금지는 제355조, 원상회복은 제358조의2, 형벌은 제473조에 있다. 카드는 규제 하나를 여러 조문에서 모은다 |
| 카드 하나에 문서 하나 | 법률이 조례에 위임한 부분은 조례에 있다. 카드는 여러 문서에 걸친다(`additional_sources`, 블록마다 `src`) |
| 없음 | 문언만으로 판단할 수 없는 점을 `open_questions`에 남긴다 |
| 없음 | 인용문마다 원문 위치(`locator`)를, 원문마다 해시(`text_sha256`)를 둔다 |

### 공고문 카드와 법률·조례 카드의 차이

| 항목 | 공고문(운행제한) | 법률·조례(절대보전지역) |
|---|---|---|
| 대상 지역 | 이름으로 정해진다("우도면 전역") | 지정 고시와 구역도로 정해진다. 조문만으로는 어느 땅인지 알 수 없다(`resolvable_from_text: false`) |
| 유효 기간 | 시작일과 종료일이 있다 | 기간이 없다. 읽은 판본의 시행일을 적는다 |
| 예외의 성격 | 해당하면 바로 허용되고 증빙만 내면 된다(`permitted_entry`) | 미리 도지사의 허가를 받아야 한다(`permit_exceptions`, `permit_procedure`) |
| 예외의 개수 | 4종 | 법률 5종. 그중 하나가 조례로 넘어가 39개 호가 된다 |
| 기존 사업 보호 | 단서로 흩어져 있다 | 별도 항이 있다(`grandfathering`) |
| 지정 기준·절차 | 없다 | 있다(`designation`). 도의회 동의가 필요하다 |
| 벌칙 | 과태료, 범칙금 | 형벌(징역·벌금), 원상회복 명령과 대집행 |

### 정리

공통 뼈대는 `card_id`, `evidence_grade`, `source`(해시 포함), `obligation_type`, `target_activity`, `target_area`, `validity`, `enforcement_status`, `restricted`, `penalties`, `open_questions`, 그리고 항목마다 붙는 `quote`와 `locator`다.

나머지(`permitted_entry`, `permit_exceptions`, `permit_procedure`, `grandfathering`, `designation`, `delegations`, `additional_sources`)는 원문에 있을 때만 두는 선택 블록이다. 세 종류 문서에 적용해 본 초안(`schema_version: 0.1-draft`)이며, 카드 수가 늘면 확정한다.

판정 값은 저촉, 제한 대상 아님, 반입 허용, **허가 대상**, 확인 필요의 다섯이다.

### 절대보전지역 카드와 상대보전지역 카드의 차이

세 번째 카드는 구조를 바꾸지 않고 만들 수 있었다. 새로 필요했던 것은 카드 사이의 참조(`refers_to`)와 관련 규제 표시(`related`)뿐이다.

| 항목 | 절대보전지역 | 상대보전지역 |
|---|---|---|
| 지정 목적 | 자연환경의 고유한 특성 보호 | 자연환경의 보전과 적정한 개발의 유도 |
| 본문의 금지 행위 | 건축, 시설 설치, 형질변경, 토지 분할, 공유수면 매립, 벌채, 흙·돌 채취, 도로 신설 등 | 건축, 시설 설치, 형질변경 등 |
| 법률의 허가 예외 | 5종 | 9종. 앞의 2종은 절대보전지역의 예외를 그대로 가져온다 |
| 조례의 허가 대상 | 제6조 39개 호 | 제7조 15개 호. 절대보전지역의 39개 호도 함께 적용된다 |
| 숙박·판매 시설 | 공원사업에서 숙박시설 제외 | 소득과 연관되는 2층 이하 건축물, 휴양펜션업 시설이 허가 대상 |
| 탐방·휴게 시설 | 자연환경보전·이용시설, 숲길 등 | 소공원, 간이휴게소, 야영장, 관망대 등(건축물은 2층 이하, 연면적 330제곱미터 이하) |
| 벌칙, 허가 절차, 원상회복 | 2년 이하 징역 또는 2천만원 이하 벌금 | 같다 |

상대보전지역 카드가 절대보전지역 카드를 참조하므로, 절대보전지역 카드가 바뀌면 상대보전지역 카드의 판정도 바뀐다. 카드 사이의 의존을 추적해야 한다.

## 4. 조례를 읽고 달라진 것

법률만 읽었을 때와 조례까지 읽었을 때 답이 달라졌다.

| 질문 | 법률만 읽었을 때 | 조례까지 읽은 뒤 |
|---|---|---|
| 조례가 추가한 지정 대상 | 알 수 없음 | 멸종위기 야생식물의 군락지, 지하수오염 취약성이 매우 높은 지역(조례 제2조제1항) |
| 허가를 받으면 가능한 행위 | 5종 | 법률 4종에 조례 제6조의 39개 호가 더해진다 |
| 허가 신청과 처리 기간 | 알 수 없음 | 신청서와 첨부 서류를 내고, 특별한 사유가 없으면 5일 이내에 처분한다. 심의·협의 기간은 빼고 센다(조례 제8조) |
| 원상회복의 절차 | 명령할 수 있다는 것만 | 이행기간을 정해 서면 통지하고, 1회에 한해 연장할 수 있다(조례 제17조) |
| 위임 대상 조례가 이 조례인가 | 이름에 따른 추정 | 조례 제1조와 제2조·제6조가 특별법의 해당 조문을 직접 가리킨다 |

**카드의 위임 부분을 채우기 전에 판정하면 틀릴 수 있다.** 법률만 읽고는 "민간 사업자의 탐방 시설 설치는 저촉"이라고 판정했는데, 조례 제6조에는 자연환경보전·이용시설(제11호), 숲길·자연휴양림(제18호) 같은 호가 있어 그 판정을 유지할 수 없다. 아래 표에 고친 판정을 적었다.

## 5. 고시와 별표로 보강한 것

수집기로 받은 원문을 카드에 더했다. 카드가 가리키는 원문이 법률, 조례, 조례 별표, 고시의 네 종류가 됐다.

| 더한 것 | 원문 | 카드의 위치 |
|---|---|---|
| 제주 전체 면적: 절대보전지역 202,195,020㎡, 상대보전지역 14,540,120㎡ | 고시 제2025-180호(2025-07-25)의 표 | `target_area.designated_areas.jeju_total` |
| 우도면 면적: 절대보전지역 1,069,157㎡, 상대보전지역 15,870㎡ | 같은 고시 | `target_area.designated_areas.udo` |
| 우도면의 최초 지정: 절대 1,069,452㎡, 상대 15,575㎡ | 고시 제2019-116호(2019-07-15) | `target_area.designated_areas.udo_first_designation` |
| 원상회복 이행기간: 행위와 규모에 따라 2개월에서 6개월 | 조례 별표 5의2 | `penalties[X2].procedure.periods` |
| 상대보전지역 지정기준인 보전지구 2등급의 내용 | 조례 별표 1 | 상대보전지역 카드의 `designation.criteria[D2].detail.grade2_criteria` |

고시의 면적 인용문은 표의 세 줄을 이어 붙여 하나로 만들었다. "우도면", "절대보전지역", "상대보전지역" 줄이 원문에서 연달아 있어야만 검사를 통과하므로, 다른 읍·면의 수치를 잘못 가져오는 실수를 막는다.

2019년과 2025년의 우도면 수치는 합계가 같고(1,085,027㎡) 절대·상대 사이의 배분만 295㎡ 다르다. 그 사이의 변경 고시(2019-12-27, 2023-01-30)는 받아 두었으나 어느 고시에서 바뀌었는지는 확인하지 않았다.

### 절대보전지역 카드

아래는 모두 "그 위치가 절대보전지역 안이라면"이라는 전제가 붙는다. 구역 데이터가 없으므로 실제 위치에 대해서는 전부 확인 필요다.

| 에코투어리즘 기획 | 판정 | 근거 |
|---|---|---|
| 제주자치도가 산책로를 설치 | 허가 대상 | 법률 E1 |
| 학술 조사를 겸한 생태 모니터링 | 허가 대상 | 법률 E3 |
| 민간 사업자가 탐방 데크와 전망대를 설치 | 확인 필요 | 법률 E1은 국가 또는 제주자치도가 시행하는 경우다. 조례 제6조제11호(자연환경보전·이용시설)나 제18호(숲길)에 해당하면 허가 대상일 수 있으나, 그 호가 인용하는 법령에서 누가 설치할 수 있는지를 읽지 않았다 |
| 공원사업으로 숙박시설을 설치 | 허가 대상 아님 | 조례 제6조제7호 단서가 숙박시설을 제외한다 |
| 지정 해수욕장 구역 안의 개장기 임시 매점 | 허가 대상 | 조례 제6조제27호. 개장 전 10일부터 폐장 후 10일까지 |
| 해안에 화장실·샤워실 외의 건축물 | 허가 대상 아님 | 조례 제6조제33호 단서 |
| 시설을 설치하지 않는 해설 탐방 프로그램 | 확인 필요 | 조례 제6조의 39개 호는 모두 시설 설치나 사업 시행에 관한 것으로 읽었다. 이런 활동을 직접 다루는 호를 찾지 못했다 |
| 우도 해안 특정 지점의 임시 시설 | 확인 필요 | 우도면에 절대보전지역 1,069,157㎡가 있다는 것은 확인했으나 그 지점이 구역 안인지는 지형도면이 있어야 안다 |

"허가 대상 아님"은 그 호로는 허가를 받을 수 없다는 뜻이다. 다른 호나 다른 법령으로 가능한지는 따로 봐야 한다.

### 상대보전지역 카드

아래도 모두 "그 위치가 상대보전지역 안이라면"이라는 전제가 붙는다.

| 에코투어리즘 기획 | 판정 | 근거 |
|---|---|---|
| 2층 이하의 숙박·판매용 건축물 | 허가 대상 | 법률 E4. 용도지역, 건축, 숙박업 등 다른 법령의 제한은 이 카드에 없다 |
| 3층 숙박시설 | 허가 대상 아님 | 법률 E4는 2층 이하다 |
| 관망대, 간이휴게소, 야영장 | 허가 대상 | 조례 제7조제9호. 건축물은 2층 이하, 연면적 330제곱미터 이하 |
| 휴양펜션업 시설 | 허가 대상 | 조례 제7조제13호 |
| 행사용 가설건축물(6개월 이내) | 허가 대상 | 조례 제7조제12호. 도지사가 특히 필요하다고 인정하는 경우 |
| 부지 3천300제곱미터 이하의 노외주차장 | 허가 대상 | 조례 제7조제8호 |
| 시설을 설치하지 않는 탐방·체험 프로그램 | 확인 필요 | "이와 유사한 행위"에 드는지 알 수 없다 |
| 우도 특정 지점의 시설 | 확인 필요 | 우도면의 상대보전지역은 15,870㎡로 좁다. 그 지점이 구역 안인지는 지형도면이 있어야 안다 |

## 7. 한계

- 공고문은 도청 게시판의 미리보기 변환본에서, 법률과 조례는 법령정보센터 웹 화면에서 얻었다. 원본과 글자 단위로 같은지는 확인하지 않았다.
- 조례 제6조 각 호가 인용하는 개별 법령은 읽지 않았다. 호의 요약은 조례 문언을 옮긴 것이고, 그 시설을 누가 어떤 조건으로 설치할 수 있는지는 담지 못했다.
- 조례의 별지 서식과 별표 2~5(관리보전지역의 보전지구별 행위제한 등)는 카드에 옮기지 않았다.
- 조례 제6조에서 관광·탐방과 관련 있다고 표시한 9개 호(`tourism_relevant`)는 작성자의 판단이다.
- 운행제한 공고가 변경한 원 공고(제2025-2407호), 「자동차관리법」 제25조, 「도로교통법」 제6조, 과태료·범칙금의 근거인 시행령 조문은 읽지 않았다.
- 우도면의 보전지역은 면적만 안다(절대 1,069,157㎡, 상대 15,870㎡). 어느 필지인지는 모른다.
- 원상회복 이행기간(별표 5의2)은 표의 칸 안 순서로 기간을 짝지었다. 원본 표로 확인하지 않았다.
- 상대보전지역 카드는 조례 제7조제14호의 10개 목을 모두 옮기지 않았고, 그 목들이 인용하는 「건축법 시행령」 별표 1은 읽지 않았다.
- 카드 3건으로는 검색과 여러 규제의 충돌 처리를 시험할 수 없다.

## 8. 다음에 할 일

1. 사람이 세 카드를 원문과 대조해 `verified`로 올리거나 고친다.
2. 2026-08-01 이후의 운행제한 연장 공고를 확보해 새 카드를 만들고 차이를 기록한다.
3. 구역 데이터의 출처를 정한다. 이것 없이는 보전지역 카드로 실제 위치를 판정할 수 없다([07 문서](07-data-composition.md) C 계층).
4. 인용문이 `locator`의 조·항·호 안에 있는지까지 검사하도록 스크립트를 넓힌다. 조문 단위 저장소(1단계)가 생기면 할 수 있다.
5. 카드 사이의 참조(`refers_to`)가 가리키는 카드와 항목이 실제로 있는지 검사한다.
