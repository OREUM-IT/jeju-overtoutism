# 0단계 결과: 우도 수집 대상 법령 목록

작성 기준: 2026-11-22(KST). 이 문서는 [로드맵](03-roadmap-and-evaluation.md) 0단계의 결과다. 목록 본체는 [`data/udo-regulation-sources.csv`](../data/udo-regulation-sources.csv)에 있다.

## 1. 결론

- 우도를 시범 지역으로 삼을 수 있다. 차량 운행제한의 근거 조문을 제주특별법 본문에서, 제한의 대상·예외·벌칙을 도 공고문에서 직접 읽었다.
- **현재 시점의 운행제한 근거 공고는 찾지 못했다.** 확보한 최신 공고(제2026-715호)의 제한기간은 2026-07-31까지다. 2029-07-31까지 연장됐다는 보도는 있으나 그 공고는 도청 게시판에서 찾지 못했다.
- 법률·조례는 법령정보센터에서, 도 공고는 도청 게시판의 첨부 미리보기에서 텍스트를 얻을 수 있다.
- 우도의 보전지역 지정 현황은 찾지 못했다.

## 2. 확인 방법

| 방법 | 내용 |
|---|---|
| 명칭·시행일 관측 | 국가법령정보센터의 이름 주소(`law.go.kr/법령/<이름>`, `law.go.kr/자치법규/<이름>`)를 열어 제목과 시행일 표기를 읽었다. 없는 이름은 제목과 시행일이 나오지 않는 것으로 구분했다 |
| 조문 읽기 | 제주특별법은 본문 전체를 받아 조문 제목 842개를 추출하고 해당 조문을 읽었다 |
| 공고문 읽기 | 제주도청 고시·공고 게시판에서 제목으로 검색하고, 첨부 파일의 미리보기 변환본으로 공고문 전문을 읽었다 |
| 공식 기록 | 국가유산포털의 지정 정보 페이지를 읽었다 |
| 2차 자료 | 보도 검색 결과 |

목록의 `check_status` 값은 다음과 같다.

| 값 | 뜻 | 건수 |
|---|---|---|
| `provision_read` | 해당 조문 또는 공고문 본문을 읽음 | 3 |
| `existence_observed` | 명칭과 시행일(또는 게재일) 표기를 관측함. 본문은 읽지 않음 | 35 |
| `official_record` | 공식 기관의 등록 정보를 읽음. 고시 원문은 아님 | 1 |
| `secondary_only` | 보도 등 2차 자료만 있음 | 1 |
| `not_found` | 찾지 못함 | 1 |

`relevance_basis`가 "작성자 추정"인 항목은 우도와의 관련성을 원문으로 확인하지 않은 것이다. 본문을 읽은 뒤 목록에서 뺄 수 있다.

## 4. 우도 운행제한 공고문에서 읽은 내용

대상: 제주특별자치도 공고 제2026-715호 「우도면 내 일부자동차 운행(통행)제한 명령 연장(변경) 공고」(2026-02-27 게재, 교통정책과). 2025-07-15의 공고 제2025-2407호를 일부 변경한 것이다. 아래는 요약이며 규제 카드로 옮길 때는 원문과 대조한다.

| 항목 | 공고문의 내용 |
|---|---|
| 근거 | 제주특별법 제432조 및 제434조제6항, 「자동차관리법」 제25조, 「도로교통법」 제6조 |
| 목적 | 교통체증에 따른 주민·방문객 안전, 도로 혼잡, 교통사고 문제의 예방·해소 |
| 제한구역 | 우도면 전역 |
| 제한기간 | 최초 2017-08-01~2018-07-31, 1차 연장 ~2019-07-31, 2차 연장 ~2022-07-31, 3차 연장 ~2025-07-31, 4차 연장 2025-08-01~2026-07-31, 4차 연장 변경 2026-03-19~2026-07-31 |
| 제한 대상 1 | 전세버스 운송사업용 자동차와 대여사업용 자동차 가운데, 공고일 이후 우도면에 차고지를 두는 사업자의 자동차, 기존 우도면 사업자가 변경등록으로 추가하는 자동차, 본거지·차고지가 우도면이 아닌 사업자의 자동차 |
| 제한 대상 1의 제외 | 승차정원 16인승 전세버스, 제1종 저공해자동차(전기·태양광·수소전기)인 대여자동차 |
| 제한 대상 2 | 우도면 안에서 대여 목적으로 운행하는 이동수단 가운데, 사용신고를 하지 않은 이륜자동차, 원동기장치자전거와 개인형 이동장치(자전거로 분류되는 것은 제외), 공고일 이후 신규 등록·운행하는 이륜자동차(사용신고를 한 전기 이륜자동차는 제외) |
| 제한 대상 3 | 「자동차손해배상 보장법」 제8조 본문에 따라 도로에서 운행할 수 없는 자동차 |
| 반입 허용 | 교통약자가 이용하는 대여자동차(장애의 정도가 심한 장애인, 65세 이상, 임신부, 일시적 휠체어 이용자, 그 동반 가족·보호자, 7세 이하 취학 전 영유아 동반), 제주도민 또는 우도면에 사업장을 등록한 자가 6개월 이상 장기 대여한 차량, 우도면 내 숙박시설을 이용하는 입도객의 대여자동차, 도지사가 인정하는 대여자동차 |
| 증빙 | 해당 사실을 증명하는 신분증·서류 제시. 도지사 인정의 경우 승인 문서 제시 |
| 벌칙 | 「자동차관리법」 제25조제1항의 운행제한 명령 위반은 같은 법 시행령 제20조에 따라 과태료 10만원. 「도로교통법」 제6조의 통행금지·제한 위반은 같은 법 시행령 제93조에 따른 범칙금(승합 5~9만원, 승용 4~8만원, 이륜 3~6만원) |

보도와 다른 점이 있었다. 전세버스 예외를 6인승 이하로 적은 기사가 있었으나 공고문은 승차정원 16인승으로 적는다.

운행제한의 현재 효력은 이 Agent가 답해야 할 대표 질문이다. 연장 공고를 확보하기 전에는 "2026-07-31까지의 공고는 확인됨, 이후는 보도만 있음"으로 답해야 하고, 시행 중이라고 단정하지 않는다.

## 6. 이번 확인에서 알게 된 것

- **조례 이름은 정확해야 한다.** "생태관광 육성 및 지원 조례"는 없고 "생태관광 육성 및 지원**에 관한** 조례"가 있다. 도립공원 조례는 "제주특별자치**도립공원** 관리 조례"로, "제주특별자치도 도립공원 조례" 식의 추측으로는 찾을 수 없었다. 1단계에서는 목록 조회로 제주도 조례 전체를 받아 거른다.
- **이름 주소가 최신 연혁을 보여 주는지 확실하지 않다.** 「유네스코 등록유산 관리에 관한 조례」는 이름 주소에서 2026-06-30 시행본이 나왔는데, 검색 결과에는 2026-08-07 시행본이 보였다. 목록의 시행일은 "이 연혁이 존재한다"는 관측이며 현행 여부는 연혁 조회로 확정한다.
- **법령 본문은 조문 단위로 나눌 수 있다.** 제주특별법 본문에서 조문 제목 842개를 패턴으로 추출했다. 부칙의 조문 번호가 본칙과 겹치므로(예: 부칙 제9조) 파서는 본칙과 부칙을 구분해야 한다.
- **도 공고의 첨부 HWP는 내려받지 않고도 읽을 수 있다.** 게시판의 미리보기가 첨부를 HTML로 변환해 보여 준다. 2단계 파서는 이 변환본을 1차 입력으로 삼고, 표가 깨지는 문서만 원본을 따로 처리하는 방식을 검토한다.
- **도청 게시판은 2016년을 경계로 둘로 나뉜다.** 2016년 이전 고시·공고는 별도 시스템에 있고 검색 화면이 다르다.
- **보도는 세부가 서로 다르다.** 전세버스 예외의 승차정원, 연장 차수 표기가 기사마다 달랐다. 보도는 원문을 찾는 단서로만 쓴다.
- **이번 확인은 웹 페이지를 읽은 것이다.** 수집기는 공식 API로 만든다. 웹 화면의 내부 요청 형식에 의존하지 않는다.
