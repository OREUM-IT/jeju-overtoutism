# 검색 도구

작성 기준: 2026-11-23(KST). 수집한 조문·별표·고시공고와 규제 카드에서 질문과 관련된 것을 찾는 첫 도구다. [로드맵](03-roadmap-and-evaluation.md) 3단계의 일부다.

## 1. 쓰는 법

```
python scripts/search.py "우도에 렌터카 가져가도 되나"
python scripts/search.py "제주특별법 제355조"
python scripts/search.py "오름 야영" --type notice --top 5
python scripts/search.py "렌터카 등록 제한" --date 2029-01-01
python scripts/search.py --check data/search-checks.json
```

수집기를 먼저 돌려 `.local/`에 원문이 있어야 조문·별표·고시공고를 찾는다. 원문이 없으면 카드만 찾는다.

## 2. 하는 일

| 기능 | 내용 |
|---|---|
| 찾는 대상 | 규제 카드 9건, 조문 4,504건, 별표 134건, 고시·공고 88건(2026-11-23 수집분) |
| 순위 | 낱말을 글자 두 개씩 겹쳐 자른 조각으로 BM25 점수를 매긴다. 형태소 분석기를 쓰지 않는다 |
| 종류별 결과 | 카드, 조문, 별표, 고시·공고를 따로 순위 매겨 보여 준다. 한 줄로 세우면 한쪽이 묻힌다 |
| 조문 바로 찾기 | "제주특별법 제355조", "자연환경보전법 제40조"처럼 법령 이름과 조 번호가 있으면 그 조문을 먼저 보여 준다 |
| 기준일 | 카드의 기간이 `--date`(기본 오늘)보다 앞서 끝났으면 "지남"이라고 알린다 |
| 최근 공고 우대 | 고시·공고는 최근 것을 조금 앞세운다. 같은 규제의 공고가 해마다 이어지기 때문이다 |
| 바꿔 쓰기 | [`data/search-aliases.json`](../data/search-aliases.json)의 목록으로 일상어를 법령 용어에 잇는다(렌터카 → 자동차대여사업) |
| 관련 없는 카드 거르기 | 질문의 말이 카드에 거의 없으면 카드를 보여 주지 않고 "찾지 못함"이라고 한다 |

표준 라이브러리만 쓰고 네트워크를 호출하지 않는다. 색인을 저장하지 않고 실행할 때마다 만든다(약 3초).

## 3. 점검 결과

[`data/search-checks.json`](../data/search-checks.json)의 질문 16개로 돌렸다. 기대값의 식별자가 조문 바로 찾기, 카드 상위 3건, 조문 상위 5건, 별표 상위 3건, 고시·공고 상위 5건 가운데 있으면 통과다.

| 조건 | 통과 |
|---|---|
| 바꿔 쓰기 목록 포함 | 16개 중 16개 |
| 바꿔 쓰기 목록 없이 | 16개 중 13개 |

**이 수치는 검색 품질의 평가가 아니다.** 질문과 기대값을 작성자가 정했고, 실패한 질문을 보며 검색 방식을 고쳤다(질문의 군말 제거, 종류별 순위, 바꿔 쓴 말의 가중치). 도구가 망가지지 않았는지 보는 점검으로만 쓴다. 평가는 검색 방식을 고정한 뒤 새 질문으로 해야 한다.

바꿔 쓰기 목록 없이 실패한 3개는 모두 일상어와 법령 용어가 다른 경우다("렌터카"와 "자동차대여사업", "해루질"과 "비어업인").

점검에 없던 질문으로도 돌려 봤다.

| 질문 | 결과 |
|---|---|
| 우도에서 전동킥보드 빌려 타도 되나 | 우도 운행제한 카드 1건. 기간이 지났다고 알림 |
| 용눈이오름 지금 올라갈 수 있나 | 자연휴식년제 카드. 용눈이오름이 해제 상태라고 표시 |
| 우도에 렌터카 가져가도 되나 | 렌터카 수급조절 카드가 1위, 우도 운행제한 카드가 2위. 순서가 바뀌어야 맞다 |
| 성산일출봉 입장료, 제주에서 드론 날려도 되나 | 관련된 카드를 찾지 못함(실제로 카드가 없다) |
| 곶자왈에 펜션 지을 수 있나 | 상대보전지역 카드 1건. 곶자왈 조례의 조문은 조문 결과에서 따로 찾아야 한다 |

## 4. 한계

- **뜻이 같아도 글자가 다르면 못 찾는다.** 바꿔 쓰기 목록은 손으로 적은 15개뿐이다. 임베딩 검색을 붙이기 전의 임시 방편이다.
- **찾는 도구이지 판정하는 도구가 아니다.** 순위가 높다고 그 조문이 그 규제의 근거인 것은 아니다.
- 카드가 없는 주제는 조문과 고시·공고만 나온다. 그 결과를 읽고 답을 만드는 일은 Agent나 사람이 한다.
- 조문의 시행일은 보여 주지만, 질문 시점에 유효한 판본만 고르는 일은 하지 않는다. 조문 저장소에 수집 시점의 현행본만 있기 때문이다.
- 지역으로 거르지 않는다. "우도"가 질문에 있어도 제주 전역의 조문이 섞여 나온다.

## 5. 다음에 할 일

1. 임베딩 검색을 더해 키워드 검색과 합친다. 참고 저장소에서 비교한 `multilingual-e5-large`에서 출발한다.
2. 검색 방식을 고정하고, 사람이 만든 새 질문으로 평가한다.
3. 지역(행정구역)과 기준일로 거르는 기능을 넣는다.
4. 이 검색을 읽기 전용 도구(`search_provisions`, `search_regulation_cards`)로 감싼다([01 문서](01-product-and-scope.md) 4절).
