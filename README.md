# 제주 오버투어리즘·에코투어리즘 정책 Agent

작성 기준: 2026-11-22(KST). **초기 기획 단계이며 구현된 코드는 없다.** 이 저장소의 문서는 모두 구현 전 제안이고, 확인한 사실과 제안을 구분해 적는다.

제주도의 관광·환경 규제를 근거 조문과 함께 조회하고, 그 위에서 오버투어리즘 대응 방향과 에코투어리즘 관광 아이템·서비스 기획을 **보고서로 생성**하는 AI Agent의 기획 저장소다. 구조는 [jeju-tour-data-analysis](https://github.com/OREUM-IT/jeju-tour-data-analysis)(제주 개인 관광 추천 Agent)를 따르되, 장소 카탈로그 대신 **규제 컴플라이언스 베이스**를 중심에 둔다.

## 무엇을 만드는가

| 기능 | 입력 | 출력 |
|---|---|---|
| A. 규제·정책 조회 | 지역·행위에 대한 질문 | 해당 규제, 근거 조문, 시행 상태, 정보 기준일 |
| B. 오버투어리즘 진단·대응 방향 | 지역·시기 | 적용 중인 규제, 부하 지표, 가능한 정책 수단과 근거 |
| C. 에코투어리즘 아이템·서비스 기획 | 대상 지역·타깃·콘셉트 | 기획안과 그 기획이 걸리는 규제 판정 |

- **독자**: 정책 담당자·관광 기획자, 관광 사업자·창업팀, 여행자. 같은 근거에서 독자별 보고서를 만든다.
- **결과물**: 대화형 답변이 아니라 보고서 한 편. 모든 서술은 근거 조문 ID를 가진다.
- **진행 방식**: 세 기능을 시범 지역 한 곳에서 얕게 먼저 만들고, 이후 지역과 법령을 넓힌다.

## 현재 상태

- 확인한 것: 국가법령정보 공동활용 사이트의 API 안내 목록에 현행 법령(조·항·호 단위), 자치법규, 행정규칙, 법령해석례, 조문별 변경 이력 조회 항목이 있다(2026-11-22, 목록 페이지 관측. 실제 API 호출은 하지 않았다).
- 확인하지 않은 것: API 이용 신청 절차, 제주 관련 법령·조례의 실제 수집 가능 범위, 아래 문서에 적은 정책 후보의 현행 여부.
- 구현: 없음. 다음 작업은 [로드맵](docs/03-roadmap-and-evaluation.md)의 0단계(수집 대상 법령 목록 확정)다.

## 기록 원칙

- 구현·관측한 사실, 사용자가 알려 준 사실, 제안을 구분해 적는다.
- 원문을 확인하지 않은 규제를 시행 중인 사실처럼 적지 않는다. 후보는 후보로 표시한다.
- 이 Agent의 출력은 법률 자문이 아니다. 모든 보고서에 정보 기준일과 확인 필요 항목을 표시한다.
- 비밀값(API 인증값 포함)과 재배포 조건을 확인하지 않은 원문 자료는 Git에 넣지 않는다.
