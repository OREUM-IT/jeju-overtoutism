# 제주 오버투어리즘·에코투어리즘 정책 Agent

작성 기준: 2026-11-22(KST). **초기 기획 단계이며 구현된 코드는 없다.** 이 저장소의 문서는 모두 구현 전 제안이고, 확인한 사실과 제안을 구분해 적는다.

제주도의 관광·환경 규제를 근거 조문과 함께 조회하고, 그 위에서 오버투어리즘 대응 방향과 에코투어리즘 관광 아이템·서비스 기획을 **보고서로 생성**하는 AI Agent의 기획 저장소다. 구조는 [jeju-tour-data-analysis](https://github.com/OREUM-IT/jeju-tour-data-analysis)(제주 개인 관광 추천 Agent)를 따르되, 장소 카탈로그 대신 **규제 컴플라이언스 베이스**를 중심에 둔다.

## 무엇을 만드는가

| 기능 | 입력 | 출력 |
|---|---|---|
| A. 규제·정책 조회 | 지역·행위에 대한 질문 | 해당 규제, 근거 조문, 시행 상태, 정보 기준일 |
| B. 오버투어리즘 진단·대응 방향 | 지역·시기 | 적용 중인 규제, 부하 지표, 가능한 정책 수단과 근거 |
| C. 에코투어리즘 아이템·서비스 기획 | 대상 지역·타깃·콘셉트 | 기획안과 그 기획이 걸리는 규제 판정 |

- **독자**: 정책 담당자·관광 기획자, 관광 사업자·창업팀, 여행자. 같은 근거에서 독자별 보고서를 만든다.
- **결과물**: 대화형 답변이 아니라 보고서 한 편. 모든 서술은 근거 조문 ID를 가진다.
- **진행 방식**: 세 기능을 시범 지역 한 곳에서 얕게 먼저 만들고, 이후 지역과 법령을 넓힌다.

## 현재 상태

- 확인한 것: 국가법령정보 공동활용 사이트의 API 안내 목록에 현행 법령(조·항·호 단위), 자치법규, 행정규칙, 법령해석례, 조문별 변경 이력 조회 항목이 있다(2026-11-22, 목록 페이지 관측. 실제 API 호출은 하지 않았다).
- 확인하지 않은 것: API 이용 신청 절차, 제주 관련 법령·조례의 실제 수집 가능 범위, 아래 문서에 적은 정책 후보의 현행 여부.
- 0단계 일부 완료(2026-11-22): 시범 지역 우도의 [수집 대상 목록](data/udo-regulation-sources.csv)을 만들었다. 법령 18건(법률 17, 시행령 1)과 조례 17건의 명칭·시행일 표기를 법령정보센터에서 관측했고, 제주특별법의 해당 조문과 우도 운행제한 공고문(제2026-715호)을 읽었다. 이 공고의 제한기간은 2026-07-31까지이며, 그 이후의 연장 공고는 보도만 있고 원문을 찾지 못했다. [결과와 한계](docs/04-stage0-udo-source-list.md)
- 규제 카드 시범 3건(2026-11-22): 위 공고문에서 [운행제한 카드](data/cards/udo-vehicle-restriction-2026-715.json)를, 제주특별법과 「보전지역 관리에 관한 조례」에서 [절대보전지역 카드](data/cards/jeju-absolute-conservation-area.json)와 [상대보전지역 카드](data/cards/jeju-relative-conservation-area.json)를 뽑고, 인용문 194개(33개, 88개, 73개)가 원문에 있는지 [검사 스크립트](scripts/check_card_quotes.py)로 확인했다. 세 카드는 모델 추출·미검수(`extracted`)다. [결과와 설계 변경](docs/05-pilot-regulation-card.md)
- 데이터 구성 계획(2026-11-22): 받을 데이터를 규범, 집행, 구역, 부하 지표, 논의·계획, 관광 자원의 여섯 계층으로 나누고 계층별 출처와 확인 수준, 저장 구조, 받는 순서를 정리했다. 구역도와 우도 단위 지표는 받을 경로를 찾지 못했다. [계획](docs/07-data-composition.md)
- 법령 API 시험 호출 통과(2026-11-22): 인증값을 발급받아 법률 1건과 조례 1건의 목록·본문을 받았다. 법률은 조·항·호로, 조례는 조 단위로 오고, 조례 별표는 HWP 파일 링크로 온다. 호출 장비의 IP 등록이 필요하다. [확인 내용](docs/07-data-composition.md)
- 법령 수집(2026-11-22): [수집기](scripts/collect_laws.py)로 우도 목록의 법령 18건과 조례 17건을 모두 받아 조문 2,818건을 조문 단위로 저장했다. 원문은 로컬 전용이고 [수집 요약](data/udo-collection-manifest.csv)만 Git에 있다. 법령은 시행일 기준으로 받아야 시행 전 판본이 섞이지 않는다.
- 별표 처리(2026-11-22): [별표 수집기](scripts/collect_annexes.py)와 표준 라이브러리만 쓰는 [HWP·HWPX 텍스트 추출기](scripts/hwp_text.py)로 별표 66건을 텍스트로 꺼냈다. 도립공원 조례 별표 1에서 우도 해양도립공원의 구역을 읽었다. 병합된 칸이 많은 표는 행이 어긋나므로 수치는 원본을 보고 옮긴다. [별표 요약](data/udo-annex-manifest.csv)
- 고시·공고 수집(2026-11-22): [고시·공고 수집기](scripts/collect_notices.py)로 도청 게시판에서 2016년 이후 게시물 137건의 목록과 규제 관련 34건의 본문·첨부를 받았다. 우도 운행제한 공고 11건의 연혁, 우도면의 보전지역 면적(절대 1,069,157㎡, 상대 15,870㎡), 우도해양도립공원 공원계획을 원문으로 읽었다. 2026-07-31 이후의 운행제한 공고는 게시판에 없었다. [게시물 요약](data/udo-notice-manifest.csv)
- 카드 보강과 제주 전역 확대(2026-11-23): 보전지역 카드 두 건에 고시의 면적과 조례 별표의 내용을 더했다. 제주도 본청의 자치법규 전체 목록 1,346건을 받아 그중 법령 14건과 조례 34건(조문 1,686건, 별표 68건)을 더 수집했고, 2016년 이후 고시·공고 424건의 목록과 사례 관련 원문을 받았다. 오름 출입·취사·야영 제한, 자연휴식년제, 렌터카 수급조절, 폐지된 비어업인 포획·채취 고시, 낚시통제구역, 한라산 탐방예약제를 원문으로 확인하고 카드 여섯 건으로 만들었다. 카드는 모두 아홉 건이고 인용문 312개가 원문과 일치한다. 아홉 건 모두 모델 추출·미검수다. [제주 전역 사례](docs/08-jeju-wide-cases.md)
- 검색(2026-11-23): [검색 도구](scripts/search.py)가 카드, 조문, 별표, 고시·공고에서 질문과 관련된 것을 찾는다. 키워드 방식이라 일상어와 법령 용어가 다르면 놓친다. 점검 질문 16개는 통과했으나 평가는 아니다. [설명과 한계](docs/09-search.md)
- 서비스 기획과 화면 시안(2026-11-23): 여행자·사업자·정책 담당자가 규제 카드로 "이렇게 해도 되나"를 확인하는 서비스를 [기획](docs/10-service-plan.md)하고, 방문 전 체크·기획 점검·지역 진단 보고서·카드 열람 화면을 [Next.js 앱](web/README.md)으로 만들었다. 판정은 우도 운행제한과 절대보전지역 카드로만 하며, 두 카드가 검수 전이라 최종 판정은 모두 "확인 필요"다.
- 읽기 전용 도구와 인용 검사(2026-11-23): Agent가 부를 [도구 6개](scripts/tools.py)와 답변의 서술마다 근거를 확인하는 [인용 검사기](scripts/verify_answer.py)를 만들었다. 웹 시안의 보고서 3종을 검사하니 규제에 관한 사실 서술은 모두 통과했고, 근거 항목이 빈 자료 상태 서술 2개가 차단됐다. 도구는 아직 명령줄로만 부른다. [결과와 정해야 할 것](docs/11-agent-tools-and-citation-check.md)
- 에코투어리즘 테마와 뱃지(2026-11-23, 제안): 규제 카드를 관광 상품으로 잇기 위해 [테마와 아이템 9건](data/eco/theme.json), [뱃지 기준](data/eco/badges.json)을 정의하고 [뱃지 상태 계산 스크립트](scripts/eco_badge.py)를 만들었다. 오늘 기준으로 예비 3건, 보류 6건이고 확인됨은 없다(카드가 모두 검수 전). 이름은 "에코투어리즘 뱃지"로 정했고, 「자연환경보전법」 제41조의3제4항의 '인증과 유사한 표시' 금지와 부딪치지 않는지 출시 전 확인이 필요하다. [정의와 한계](docs/12-eco-theme-and-badge.md)
- 배포 화면과 제주 전역 확장 기획(2026-11-23): 「규제 확인」은 오름잇(oreumit.com, `OREUM-IT/jeju-tour`)의 화면으로 배포되어 있고, 이 저장소의 카드와 테마 정의를 사본으로 가져다 쓴다. 에코투어리즘 탭은 그 저장소의 PR #67로 들어갔다. 화면의 판정은 아직 우도 운행제한과 절대보전지역 카드로만 한다. 이를 장소 유형과 활동 단위로 제주 전역에 넓히는 [기획](docs/13-jeju-wide-expansion.md)을 쓰고 1단계(전역 틀)를 만들었다: [장소 유형 9개](data/place-types.json), 카드의 유형 태그, [유형별 커버리지](data/coverage.json)와 [계산 스크립트](scripts/coverage.py). 유형 9개 가운데 3개(곶자왈·습지·숲, 세계자연유산·천연기념물, 도립공원)는 카드가 없다. 2단계로 있는 카드 7건에 판정 규칙을 붙여(오름, 한라산, 낚시, 해루질, 상대보전지역, 렌터카 사업) 카드 9건 모두에 규칙이 생겼고, 예시 표를 기획 문서 6.2절에 적었다. 규칙의 구현은 jeju-tour에 있다.
- 구현: 법령·조례 목록·별표·고시공고 수집기, HWP 텍스트 추출기, 카드 원문 발췌와 인용문 검사 스크립트, 검색 도구가 있다. 임베딩 검색과 Agent는 없다. 다음 작업은 2026-08-01 이후 연장 공고 확인(소관 부서 문의), 수집한 원문으로 카드 보강, 검색 구성이다. [필요한 키와 데이터](docs/06-api-keys-and-data-needs.md)

## 기록 원칙

- 구현·관측한 사실, 사용자가 알려 준 사실, 제안을 구분해 적는다.
- 원문을 확인하지 않은 규제를 시행 중인 사실처럼 적지 않는다. 후보는 후보로 표시한다.
- 이 Agent의 출력은 법률 자문이 아니다. 모든 보고서에 정보 기준일과 확인 필요 항목을 표시한다.
- 비밀값(API 인증값 포함)과 재배포 조건을 확인하지 않은 원문 자료는 Git에 넣지 않는다.
